# Phase 9 portable sharing

Run `uv run python -m frictionlab export-static <RUN_UUID> --output <NEW_DIRECTORY>` from the repository root. The command reads the latest complete saved audit under `artifacts/phase5` by default; use `--root` for another local cohort artifact directory. It creates a self-contained `index.html` and importable `bundle.json`. Open the HTML directly in a browser without the Python API, Streamlit, DuckDB, a network connection, or a model service. The default manifest says `private_local`; nothing is uploaded automatically.

The viewer has severity filtering, synthetic outcome and milestone bars, ordered masked screenshot playback, and compatible click overlays. Use **Open a local private bundle** to inspect another JSON bundle entirely inside that browser tab. The viewer uses text nodes for report content, accepts only bounded embedded PNG data, and does not execute captured HTML, DOM, ARIA, script, or SVG. A strict content security policy blocks all network connections and external scripts, fonts, frames, and objects. The exporter includes selected masked screenshots and an allowlisted report projection; planner prompts, raw traces, headers, credentials, and original evidence paths are excluded. It redacts URLs, email addresses, authorization/API-key/password assignments, and common token formats. Individual images are limited to 2 MiB; the complete import is limited to 20 MiB. A saved report may still contain unexpected personal information visible in screenshot pixels or prose, so **inspect the finished bundle before sharing**.

For a fixture-only public example, pass `--public-fixture`. This flag refuses a report unless its recorded build and observed protection scope match the bundled storefront. The included `examples/phase9-static` directory is a sanitized synthetic example. To publish it, create a Hugging Face **Static** Space and copy its `README.md` and `index.html` into the Space repository. Publication is optional; do not publish a private `bundle.json` or any run artifacts. [Hugging Face documents Static Spaces as free for everyone](https://huggingface.co/docs/hub/spaces-sdks-static). Its current [Spaces overview](https://huggingface.co/docs/hub/spaces-overview) says compute-backed Gradio/Docker Space creation requires a paid plan, so the original CPU-hosted Streamlit sharing idea is not the zero-credit-card path. Static Space variables and secrets are accessible to client-side JavaScript; this viewer needs neither.

Optional Groq/Gemini acceleration is **not enabled in Phase 9**. The original named models and free quotas are time-dependent; the product remains local-only for inference and never makes an unapproved cloud model call or paid fallback. A future opt-in adapter needs a current free-tier eligibility check, explicit request/token limits, bounded retries, a local fallback, provider-switch provenance, and confirmation that the data sent to a provider is acceptable. The existing strict matched comparison must reject mixed-provider sessions unless explicitly designed for them. No external model smoke request is part of this phase because no cloud adapter ships.

Phase 9 validation opens the exported HTML from a `file:` URL, imports a local bundle, checks filtering and screenshot playback, rejects malformed/external image payloads, and verifies that review generates no HTTP requests to the tested fixture. It also inspects a public fixture example and tests redaction with fake credential and URL markers.
