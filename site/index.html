Your machine. Your evidence.

Run locally.
Share deliberately.

The browser, agent runtime, DuckDB storage and dashboard run on your machine. Reports stay local. Offline playback uses saved evidence and makes no requests to the tested website.

There is no FrictionLab account or subscription. Open the sample report without installing anything, or download the Python source to run the tool.

Current supported scope

Bundled disposable fixtures only. External deployed products and arbitrary staging URLs remain blocked until replica isolation is proven.

Bring your own API key

Run the installable CLI with your own Groq or Gemini key, or use a local model without a key. Cloud inference sends bounded sanitized semantic inputs to your provider. Check the installation guide for configuration and verification status.

Synthetic results support investigation; they do not establish human conversion or churn rates.

Get started

Download the source.
Open the local tool.

Use Python 3.12 and uv. Follow the setup guide for your local browser and optional model resources. Public availability depends on repository visibility; development wheel/source archives are available through the Phase 10 build workflow.
