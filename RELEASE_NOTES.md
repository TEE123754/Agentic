# FrictionLab 0.1.0 — local assessment preview

FrictionLab is a local, open-source website quality assessment tool with a CLI dashboard and native Windows launcher. Paste a URL, select any of six categories, and review an exportable scored report with coverage, severity-ranked issues, evidence, reproduction steps, recommendations, skipped checks and limitations. Optional AI advice uses your own explicitly connected Groq or Gemini account; availability of a free tier depends on that account and model. No API key, model weights or personal reports are included in these downloads.

**Downloads:** `FrictionLab-windows-x64.zip` is a portable Windows application. Extract it and open `FrictionLab.exe`; an existing Chrome or Edge installation is needed for offline viewport/axe checks. `frictionlab-0.1.0-py3-none-any.whl` and `frictionlab-0.1.0.tar.gz` are Python 3.12 distributions. Compare downloaded files with `SHA256SUMS`. The binary is not code-signed. macOS/Linux frozen applications are not qualified; source/CLI mode is available there.

**Production protection:** URL-only mode makes no website request. Uploaded offline HTML/ZIP snapshots are rendered at a synthetic origin with application scripts removed, strict CSP and external requests blocked. The optional public-page capture sends one explicitly approved GET; a GET can still change server logs or state. Browser isolation alone does not guarantee safety for a live product. Dynamic functionality, personas, authenticated flows, Core Web Vitals and intrusive security tests require a verified isolated replica/backend, sandboxed services or additional access; unsupported checks are skipped. Existing autonomous personas are qualified only against bundled owned fixtures. Synthetic abandonment is not human churn.

**Evidence:** The owned-fixture release gate passed 265 distinct regression cases, including a real three-profile healthy checkout (3/3) and a reviewed partial defect baseline with two planner-fault exclusions. The offline workspace gate passed 51 initial cases plus three affected cases, installed wheel/dashboard/export acceptance and a zero-contact sentinel. The Windows native gate passed 2/2 and the extracted ZIP ran an offline browser/axe/report smoke with three screenshots and zero target requests. Live API provider/account behavior has not been verified; no paid fallback is configured. See `IMPLEMENTATION_PLAN.md`, `docs/local-assessment.md`, `LICENSE` and `THIRD_PARTY_NOTICES.md`.
